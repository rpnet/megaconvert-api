# Contributing

Thank you for your interest in contributing! This repo contains both API documentation and a curated list of file conversion resources.

## Awesome File Conversion List

### What to add
- **Online tools** — Free or freemium file conversion services
- **CLI tools** — Command-line utilities for file conversion
- **Libraries & SDKs** — Programming libraries for handling file format conversion
- **APIs** — Developer APIs for file conversion
- **Articles & Guides** — High-quality tutorials and format guides

### Quality standards
- Tools must be **actively maintained** (updated within the last 2 years)
- Online tools must be **functional and accessible** (no broken links)
- Libraries should have **meaningful adoption** (50+ GitHub stars or equivalent)
- No duplicate entries — check if the tool is already listed

### How to submit

1. Fork this repository
2. Add your entry in the appropriate category in README.md
3. Use the existing format:
   - Online tools: `[Tool Name](URL) — Brief description`
   - Libraries: `[library-name](URL) (Language) — Brief description`
4. Keep descriptions concise (under 100 characters)
5. Add entries in alphabetical order within their category
6. Submit a Pull Request with a clear description

### What NOT to add
- Abandoned projects (no updates in 2+ years)
- Tools that require payment with no free tier
- Malware, adware, or tools with deceptive practices
- Duplicate entries

## API Documentation & Examples

If you find errors in the API docs or want to add examples in a new language, PRs are welcome.

## Code of Conduct

Be respectful and constructive. We're here to build a useful resource for everyone.
